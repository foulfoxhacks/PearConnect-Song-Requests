A few steps, then you’re ready to test. PearConnect keeps requests paused until you enable them.

1

Choose your connection

Both options use the same request rules and work in the desktop or CLI.

2

Connect music

Open Pear Desktop and enable its API Server plugin. Approve the authorization prompt in the player; PearConnect saves the credential securely.

3

Connect chat

For Simple, keep TikFinity Desktop running and connected to your livestream. For Advanced, import the action package and configure Streamer.bot.

4

Set your request rules

Choose commands, cooldowns, duration limits, blocklists and allowed users.

5

Test safely

Validate a sample request without contacting the player, changing playback or spending a request slot. Duration and search-result checks require a real request.

6

Enable requests

Test the player connection first. An open chat socket alone doesn’t prove commands are arriving.
