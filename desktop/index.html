Prove the connection, one step at a time.

GUIDED TEST

Keep music playing while you test. Requests pause during validation; the test command never adds a song.

Choose Simple or Advanced in the setup reference below first. You’ll need a live TikTok chat to verify delivery.

  1. Player
  2. Live command
  3. Song & rules
  4. Enable

1. Connect and authorize the player

Open Pear Desktop, enable the API Server plugin, then approve PearConnect. This check only reads the current track.

2. Send a real command from your livestream

Copy this exact command and send it in your TikTok LIVE chat. PearConnect will catch it safely before searching or queuing anything.

Command isn’t arriving?

The local “Test integration” button checks the local endpoint only. It does not prove that TikFinity sent this chat command. Overlay warnings in TikFinity relate to its visual actions; PearConnect song requests do not require an OBS overlay.

3. Search a song without adding it

Use a viewer who is allowed by your rules. This reads a real search result and checks its title, artist and duration. It does not enqueue music or consume cooldowns and request slots.

4. Ready to accept requests

The player responded, your live request command arrived, and a sample song passed the rules. This does not verify TikTok chat replies, skipping, or actual enqueue playback.

Enable requests, then have a viewer send their first song. Look for Enqueue confirmed in your activity feed; playback starts when the player reaches that track.

WHEN CHAT COMMANDS WON’T CONNECT

Keep your community in the queue.

Create a temporary code that viewers can use on the PearConnect website. Your desktop stays open and checks every song through the same request engine.

This selects website requests as your TikTok fallback. TikTok commands are suspended until you end the session; Twitch and YouTube stay independent. Pausing requests leaves existing music playing.
VIEWER SESSION CODE

What your viewers should expect

  1. Visit pearconnect.mellozone.site/sessioncode and enter your code.
  2. Enter a display name and an artist and song.
  3. Wait for the result. “Received” is not a queue confirmation.

Website names are unverified. A restricted request allowlist disables this fallback. Website cooldowns and limits use a private identifier derived from the viewer’s network connection, so people sharing a connection share those limits. TikTok and website identities cannot be combined reliably.

Only submitted requests go through the relay. Player tokens remain on this computer. Closing Desktop ends the session when connected; after an abrupt disconnect, the relay stops accepting requests and the code expires at its deadline.
